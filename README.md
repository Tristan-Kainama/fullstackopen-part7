# Full Stack Open, Part 7

This repository contains my completed exercises for Chapter 7 of the [Full Stack Open](https://fullstackopen.com/en/part7) course. It includes a routed anecdotes application and a full-stack bloglist application, along with separate end-to-end test suites.

## Projects

- **routed-anecdotes**: A React application for browsing and creating anecdotes, using client-side routing and a JSON Server API.
- **bloglist**: A full-stack blog application with a React client and an Express API backed by MongoDB.
- **routed-anecdotes-tests** and **bloglist-tests**: Playwright end-to-end tests for the applications.

## Tech Stack and Libraries

- **Frontend:** React, Vite, React Router
- **Bloglist state and UI:** Zustand, Material UI, Axios
- **Backend:** Node.js, Express, MongoDB, Mongoose
- **Authentication and security:** JSON Web Tokens (`jsonwebtoken`), `bcrypt`
- **Anecdote API:** JSON Server
- **Testing:** Playwright, Vitest, React Testing Library
